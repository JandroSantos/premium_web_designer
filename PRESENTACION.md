# 🚀 Premium 3D Web Design Skill for Manus

> **Transforma ideas simples en experiencias web cinematográficas de alta gama.**

Esta skill es una extensión avanzada diseñada para dotar a los agentes de IA con la capacidad de concebir y desarrollar interfaces web que siguen los estándares de **Awwwards** y el diseño **Premium moderno**. Se especializa en la integración de profundidad 3D, efectos de cristal líquido (*Liquid Glass*) y narrativas visuales basadas en el desplazamiento (*Scroll Storytelling*).

---

## ✨ Características Principales

La skill ha sido entrenada con patrones de diseño de élite, permitiendo ejecutar las siguientes capacidades de forma nativa:

| Capacidad | Descripción Técnica | Resultado Visual |
| :--- | :--- | :--- |
| **3D Inmersivo** | Integración de modelos en tiempo real y sistemas de partículas. | Experiencias táctiles y dinámicas. |
| **Liquid Glass** | Estética de glassmorphism avanzado con desenfoque y bordes de gradiente. | UI sofisticada y moderna. |
| **Cinematic Scroll** | Control total de capas y parallax mediante variables CSS y GSAP. | Narrativa fluida al navegar. |
| **Micro-interacciones** | Animaciones de entrada y estados hover de alta fidelidad. | Sensación de producto premium. |

---

## 🛠️ Tecnologías Dominadas

Esta skill instruye a la IA para trabajar con las librerías más potentes del ecosistema web actual:

*   **Motor 3D:** Three.js, React Three Fiber y Spline.
*   **Animación:** GSAP (GreenSock), Framer Motion y CSS Keyframes.
*   **Layout & Estilo:** Tailwind CSS y variables CSS dinámicas.
*   **Frameworks:** React, Vite y TypeScript para robustez técnica.

## 🚀 Cómo Empezar

### Para Usuarios de Manus
1.  **Descarga** el archivo `.zip` de la skill.
2.  **Arrastra** el archivo a tu chat con Manus.
3.  Di: *"Instala esta skill y úsala para mi próximo proyecto web"*.

### Para otras IAs (Claude, GPT-4, etc.)
Copia el contenido del archivo `SKILL.md` y los prompts de referencia en las instrucciones del sistema para que la IA adopte este estilo de diseño superior.
